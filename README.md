# Plasmod 数据库管理台

基于《Plasmod 本地接入与接口指南》的本地前端演示。使用 HTML、CSS 和原生 JavaScript，无需安装 npm 依赖。

## 本地启动

在项目目录执行：

```powershell
npm start
```

然后打开 http://127.0.0.1:5180 。无需 npm install，Node.js 18 或更高版本即可。也可通过 PowerShell 执行 `./start.ps1`。按 Ctrl+C 停止服务。若仅安装 Python，可改用 `python -m http.server 5180 --bind 127.0.0.1`。

## 功能

- 数据库总览：库存分布、健康、模式、可见水位、节点、性能；系统详情包含存储、索引与分段。
- Agent 管理：登记、全局列表、工作区与角色筛选。
- 会话管理：登记、按 Agent 筛选、查看关联记忆。
- 记忆管理：事件写入、列表筛选、更正、遗忘、过时、操作回执查询。
- 查询与溯源：对象 ID 查询、模拟文本检索、结构化证据、专项召回、test 四链快照、对象关系与版本详情。
- 对象管理：状态、产物、关系、治理记录登记及查询；内联 Markdown 预览。
- 共享与裁决：共享合约登记和查询、记忆共享、冲突裁决回执。
- 记忆维护：准入、更新、衰减、摘要、压缩演示；范围选择、分页游标、维护和提炼回执查询。
- 来源清理：逻辑删除和物理清理预览、确认及结果展示。

## 演示范围

所有数据和结果均为模拟，没有连接数据库。界面操作保存在当前浏览器 origin 的 localStorage 中，键名 `plasmod-demo-v1`。删除此项并刷新可恢复初始数据。

事件与对象 ID 自动生成。记忆检索采用简单关键词匹配，不模拟数据库真实算法。维护操作以演示回执为主；摘要会生成模拟记忆，更新仅在传入数值信号时改变演示字段。没有提炼回执的事件按文档展示 404。冲突裁决仅展示回执，不推断文档未描述的生命周期变化。异步清理参数仅用于展示，演示执行在本地同步完成。

没有新增完整聊天记录时间线、历史趋势数据、Agent 删除等文档未提供的能力。Logo 为用户提供的 Plasmod 与 CodeSoul 原图。
